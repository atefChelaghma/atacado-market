# UI/UX Design Skill

## Objective

Create a coherent, accessible interface that serves user goals and supports the product's business model without sacrificing trust or usability.

## Workflow

1. **Understand the brief**
   - Identify target users, key tasks, content types, business goals, platforms, and constraints.
   - Separate confirmed requirements from assumptions.
   - If reference websites are supplied, identify transferable patterns; do not copy their branding, exact layouts, or proprietary assets.

2. **Inspect before redesigning**
   - For an existing product, inspect screenshots, current components, routes, design tokens, and responsive behavior before proposing changes.
   - Preserve strong existing decisions. Prefer targeted improvements over an unnecessary full redesign.

3. **Define the system**
   - Establish typography, color tokens, spacing, grid, breakpoints, borders, imagery rules, interaction states, and accessibility expectations.
   - Define reusable components and variants before multiplying pages.
   - Keep content/data separate from presentation.

4. **Design user journeys**
   - Map the main entry points, decisions, actions, success states, empty states, and error states.
   - Make primary actions obvious without making every element a call to action.
   - Design desktop and mobile intentionally; do not merely shrink desktop layouts.

5. **Validate**
   - Check hierarchy, readability, consistency, responsiveness, keyboard use, contrast, and touch targets.
   - Explain trade-offs and prioritize fixes by user impact.

## Output

Provide:

- A short design diagnosis.
- Prioritized improvements.
- Design-system and reusable-component recommendations.
- Screen/page templates needed.
- Responsive and accessibility notes.
- A concise implementation-ready prompt or specification when useful.

## Guardrails

- Do not invent user research, analytics, ratings, testimonials, or performance data.
- Do not claim an interface is accessible without validation.
- Do not copy a reference site's exact visual identity.
- Prefer evidence-based and clearly labeled recommendations.
